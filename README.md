# QRKot

QRKot - учебный API-сервис благотворительного фонда поддержки котиков.
Приложение позволяет создавать целевые проекты, принимать пожертвования
и автоматически распределять свободные средства между открытыми проектами.

## Возможности

- Регистрация пользователей и JWT-аутентификация.
- Создание, просмотр, обновление и удаление целевых проектов.
- Создание пожертвований авторизованными пользователями.
- Просмотр пользователем собственных пожертвований.
- Просмотр всех пожертвований суперпользователем.
- Автоматическое инвестирование пожертвований в открытые проекты.
- Автоматическое закрытие полностью профинансированных проектов и
  полностью распределённых пожертвований.
- Swagger-документация доступна по адресу `/docs`.

## Доступы

- `GET /charity_project/` доступен всем пользователям.
- `POST /charity_project/`, `PATCH /charity_project/{project_id}`,
  `DELETE /charity_project/{project_id}` доступны только суперпользователю.
- `POST /donation/` и `GET /donation/my` доступны авторизованному
  пользователю.
- `GET /donation/` доступен только суперпользователю.
- `/auth/register`, `/auth/jwt/login`, `/auth/jwt/logout`, `/users/me`
  и `/users/{id}` предоставляются через `fastapi-users`.

## Основная логика

В проекте используются основные модели:

- `User` - пользователь сервиса.
- `CharityProject` - целевой проект с названием, описанием и требуемой суммой.
- `Donation` - пожертвование с суммой, необязательным комментарием и автором.

Когда создаётся пожертвование, оно распределяется по самым ранним открытым
проектам. Когда создаётся проект, в него распределяются самые ранние свободные
пожертвования. Если сумма объекта полностью распределена, он получает
`fully_invested=True` и дату закрытия `close_date`.

## Технологии

- Python
- FastAPI
- fastapi-users
- SQLAlchemy async
- SQLite
- Alembic
- Pydantic

Установите зависимости:

```bash
pip install -r requirements.txt
```

Примените миграции:

```bash
alembic upgrade head
```

Запустите приложение:

```bash
uvicorn app.main:app --reload
```

Документация будет доступна по адресу:

```text
http://127.0.0.1:8000/docs
```
